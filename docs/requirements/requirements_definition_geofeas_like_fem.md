# GeoFEM 2D FEM 要件定義

## 方針

GeoFEMは2D平面ひずみ解析専用アプリケーションとする。3D解析機能、
旧v26バックエンド、3D入力の委譲経路、3Dメッシュ/要素/回帰要件は
削除済みとし、今後の実装対象にも含めない。

## 対象解析

- 2D平面ひずみ静的解析
- 弾塑性材料解析
- SRM
- geostatic/K0
- 掘削/death/deactivate
- u-p/圧密
- Riks/arc-length
- 機械・水理インターフェース

## 対象要素

- `TRI3`
- `TRI6`
- `QUAD4`
- `QUAD8`

## 性能要件

- 2D専用コアで高速に実行する。
- SciPy疎行列とNumba JITを必須利用可能な前提にする。
- 旧3Dバックエンドへの委譲や3Dコード共有による高速化は行わない。

## 入出力

- YAML/JSON入力
- CSV/VTK/HTML/JSON出力
- 2D平面ひずみとして `eps_z=0` と `sigma_z` を出力する。
  これは平面ひずみ構成則の結果であり、3D解析機能ではない。

## 非対象

- 3Dソリッド要素
- 3D CADメッシュ生成
- 3Dビュー/断面表示
- 旧v26 YAML実行
- 3D回帰ケース
