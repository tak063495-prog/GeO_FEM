# GeoFEM GUI ユーザーガイド

この文書は GUI の `helpId` から直接参照される操作ガイドです。画面、入力エラー、帳票項目、設定ウィジェットのツールチップに表示される `docs/user_guide.md#...` のリンク先を安定化します。

## workspace

モデル表示、コマンドバー、プロジェクト操作、ログを確認するメイン画面です。上面の作業ウィザードで次工程を確認し、左のツリーまたは上面リボンから対象画面へ移動します。

## workflow

GeoFEAS 風の入力順を、現在の進捗、次に行う作業、工程一覧、操作ショートカットとして表示します。必須入力が不足している場合は、不足箇所と移動先を確認して順に解消します。

## analysis

解析種別、2D 指定、単位系、GeoFEAS/VGFlow 代替プロファイル、ソルバー基本条件を設定します。最初にここを確認すると、以降の入力診断が安定します。

## geometry

形状線、CAD 取込、閉領域、トンネル、補助線、近接点、交点分割、修復候補を扱います。形状を確定してからメッシュ分割へ進みます。

## mesh

要素種別、分割数、局所細分、品質チェック、QUAD4/QUAD8 連携、VGFlow/GeoFEAS メッシュ変換を設定します。モデルチェックで品質警告を確認してください。

## materials

弾性、弾塑性、液状化、高度材料、ジョイント、ばねなどの材料条件を設定します。単位、強度、履歴変数、構成則の適用範囲を確認します。

## external

SXF、DXF、GF1、DWG 変換器、VGFlow 2D 連携 CSV/JSON、外部製品診断を扱います。非公開ネイティブ形式は公開代替形式へ変換して管理します。

## boundary-conditions

拘束、ローラー/ピン支点、MPC、水位、水圧、浸透境界、ステージ内境界条件を設定します。節点や辺の選択状態を確認してから登録します。

## loads

節点荷重、分布荷重、自重、地震荷重、水圧荷重、荷重ケースを設定します。ステージ解析では、適用ステージと有効/無効の状態を確認します。

## stages

施工ステージ、要素有効化、材料変更、応力解放率、掘削、承認履歴を管理します。応力解放率は累積 100% 管理の診断対象です。

## solver

線形/非線形ソルバー、収束条件、時間積分、Riks、連成解析、ログ出力を設定します。実行前にモデルチェックを通してください。

## model-check

解析前の ERROR/WARN/INFO を一覧します。ERROR は解析前に解消し、入力エラー行から対象セルへジャンプできます。

## results

左ツリーの「結果」を展開して、応力コンター、変位ベクトル、変位コンタ、FL/安全率、履歴を選択します。右ペインは結果図の置き場ではなく、ステージ/時刻、時間経過スライダー、変形倍率、表示成分、色表示の調整に使います。応力コンターなどを表示している場合も、同じステージに変位結果があれば変形後メッシュを重ねて確認できます。大規模結果はページングと表示品質制御を使います。

## report

HTML/PDF 計算書、WYSIWYG 帳票ページ、Post 図配置、manifest、監査結果を作成・確認します。帳票の再現性は入力ハッシュと固定化 manifest で確認します。

## yaml

GUI 入力と YAML の往復編集を行います。GUI 変更後は YAML へ反映し、外部編集後は GUI へ同期してください。

## errors-input-cell

入力エラー一覧の各行は、対象テーブル、行、列、フィールド、診断メッセージを持ちます。行を選択して「エラーセルへ」を実行すると、該当セルへ移動します。値の単位や範囲を確認し、必要なら一括修正後に再度モデルチェックを実行します。

## report-item

帳票ページ項目は、種別、ソースまたは本文、タイトル、ページ内の x/y/w/h を持ちます。Post 図や判定表を追加した後、プレビューで紙面内に収まること、文字が見切れないこと、必要な manifest が出力されることを確認します。

## report-audit

Post/帳票監査では、出力物、PDF/HTML、画像差分、manifest、入力ハッシュ、固定化スナップショットを確認します。監査結果は成果物の再現性説明に利用します。

## settings-input

設定入力欄では、GUI 値、YAML 値、単位、推奨範囲、禁止範囲を確認します。変更後はモデルチェックまたはワークフロー診断を更新し、未反映の入力がないことを確認します。
