# GeoFEM 開発履歴・失敗分類アーカイブ

このフォルダーは、GeoFEM 2D 開発で確認された失敗・不具合・検証上の未確定事項を、今後の開発で参照できる形に整理したものです。

- `DEVELOPMENT_FAILURE_HISTORY_JA.md`: 時系列、失敗分類、原因、影響、対策、残存リスク
- `failure_inventory.json`: 失敗項目を機械処理できる形式で記録
- `failure_timeline.csv`: 開発マイルストーンと失敗・改善の時系列
- `evidence/`: 既存のToDo、レビュー、検証結果、代表ログの複製

## 読み方

証拠レベルは次のとおりです。

- `確定`: ファイル、ログ、テスト記録から直接確認できる
- `推定`: 会話記録や複数ログから妥当性が高いと判断できるが、単独の再現証拠が不足
- `未解決`: 改善実装はあるが、実ケースまたは別環境での再検証が必要

Gitには作業時点でコミット履歴がなく、作業ツリーも未追跡状態でした。このため、厳密なコミット単位の履歴ではなく、プロジェクト内の資料・ログ・テスト記録と会話上のマイルストーンを突合した再構成です。
